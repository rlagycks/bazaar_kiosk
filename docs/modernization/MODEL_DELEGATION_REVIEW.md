## 현재 상태를 전달할 때 반드시 포함할 내용

1. PR36·38 머지로2A/1A는 완료했다.1B 전체는 미완료이며2B를 완료로 취급하지 않는다.
2. PR40에는 D-P07 승인으로 적용한0020과 그 회귀 테스트가 담겨 있다. 추가 migration 수정은 새 승인이 필요하다.
3. 0020만 승인되더라도0019의 과거 주문 삭제·테이블 재배정·제약 완화는 범위 밖이다.
4. PG 일일 미초기화(BK-R003)는 남으며0020 패치 승인과 번호 정책/운영 위험 수용은 다르다.
5. 정확한 테스트 수집·실행·skip 수와 명령은 [현재 인계](SESSION_SETUP.md)를 그대로 인용한다.
   이 문서에 수치를 중복 기록하지 않는다.
6. PG는 migration 경로와 앱 테스트를 별도 명령으로 실행한다. 어떤 실패도 테스트를 삭제하거나
   migration을 fake해 통과시키지 않는다.
7. 기존 CI는 check/drift다. CI 녹색을 후보 PG 테스트 수행 증거로 사용하지 않는다.
8. 새 작업마다 기준 ref·최신 변경·소유 파일·실행 명령·종료 조건을 명시한다.
   명령 실행이 막히면 미실행 이유를 기록하고 통과를 추정하지 않는다.
